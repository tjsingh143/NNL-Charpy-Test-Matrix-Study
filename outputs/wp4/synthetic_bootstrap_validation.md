## 4. Coverage of 95 % percentile intervals (WP3 scenarios, final method)

200 synthetic data sets per scenario (WP3 replicates 0-199); 500 bootstrap replicates per data set and method (1600 bootstrap runs). Coverage counts only reportable intervals (finite-target fraction >= 95 %); the nominal level is 95 %, and the Monte Carlo standard error of an estimated coverage of 95 % is shown. The empirical SD is the spread of the original estimate over the synthetic data sets (the actual sampling SD for this fixed design); the ratio compares the median bootstrap SD with it. Full-size truths have LSE 5 J while the final method fixes 2.7 J, so the original estimates carry the small bias recorded in WP3 (D-042).
