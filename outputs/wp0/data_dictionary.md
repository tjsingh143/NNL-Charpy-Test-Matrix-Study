# Data dictionary - Charpy impact test dataset

Dataset: Materials Cloud record eny5v-www93 (DOI 10.24435/materialscloud:gh-za, issued 2024-12-19). Workbook sheet `Charpy Data`: 4775 records (spreadsheet rows 3-4777), 55 columns.

Generated by `src/wp0_data_dictionary.py` from the vendored raw file. Meanings and notes come from `src/curated_metadata.py` (sources: the workbook's own Column Descriptions sheet, the descriptor paper Lee et al. 2025, ASTM E23-82 and ISO 148-1:2016). Where a meaning is uncertain the note says so.

How to read the fill columns: *all* = all records; *ferritic* = the 4062 records whose Material Group is 'Reactor pressure vessel steel' (everything except the out-of-scope SS316 family). Fill-rate bands (D-026): >=95% complete or nearly complete; 50-95% partially populated; 10-50% sparse; <10% very sparse (unusable for dataset-wide analysis). Blank cells mean *not reported*; nothing has been filled in. Bands describe dataset-wide coverage: a field that only applies to some records (e.g. fluence, which exists only for irradiated specimens) can be complete for those records yet fall in a low band; conditional completeness is given in `notable_facts.md`.
